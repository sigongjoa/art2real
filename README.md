# 사업 — 원화에서 원형까지

> 정한 날 2026-09-08. 이 파일이 트랙 우선순위의 단일 출처다.
> 트랙마다 적힌 목적이 이것과 어긋나면 **이쪽이 맞다.**

## 파는 것

    2D 원화밖에 없는 IP 소유자에게, 입체 굿즈의 원형과 실물 샘플을 며칠 안에 준다.

양산은 안 한다. **공장 앞단에 앉는다.**

## 누구에게

개인·소규모 IP 소유자 — 웹툰·버튜버·인디게임·SNS 캐릭터. 펀딩(텀블벅·와디즈)으로
굿즈를 내려는 쪽.

## 왜 지금 비어 있나

| 인디 IP 가 가진 것 | 필요한 것 | 지금 값 |
|---|---|---|
| **2D 그림만** | 3D 원형 | 조형 외주 수백만 원 ⚠ 시세 미조사 |
| — | 몰드 · 캐스팅 | 대행 많음. 병목 아님 |
| — | 양산 | 중국 공장. 병목 아님 |

**병목은 원형 하나다.** 그래서 인디 굿즈가 전부 아크릴·키링으로 끝난다 — 2D 를 그대로
쓸 수 있는 것만 만들 수 있어서다.

그리고 펀딩에는 닭-달걀이 있다.

    펀딩 열려면 → 실물 사진 → 샘플 → 공장이 움직여야 → 돈 → 그 돈이 펀딩에서 나온다

지금은 렌더 목업으로 때운다. **펀딩 전에 실물을 쥐어주는 것**이 상품이고, 이건 시간
문제라 자본으로 안 풀린다.

## 무기 셋

| | 무엇 | 어디서 나오나 |
|---|---|---|
| 1 | **원형 원가를 무너뜨린다** | `11_애니3d` — 원화 3판 → 좌표창 → hull → 판 분해 |
| 2 | **닮음을 숫자로 답한다** | 같은 트랙의 실루엣 IoU · 원화 위 겹치기. 굿즈 업계는 "느낌 어떠세요"로 판다 |
| 3 | **소재를 섞는다** | 대형 사출 라인은 공정이 하나라 못 한다. 레진 + 펠트 + 원단 |

3번은 고객이 생긴 뒤다. 1·2 가 사업을 연다.

## 안 하는 것

| | 왜 |
|---|---|
| 평면 굿즈 (아크릴 · 키링 · 스티커) | 그림이 곧 제품이라 우리 도구가 값을 못 낸다. 대행 수십 곳. 포화 |
| 양산 수탁 | 재고 · MOQ · 처리량. 1인이 300개 후처리를 못 한다 |
| 반다이와 정면 | 라이선스와 금형은 자본 게임. 그쪽 가격의 상당분은 **리셀 프리미엄이라 반다이 매출도 아니다** |
| 자체 IP 피규어 판매 | 나중. 지금은 남의 IP 를 대신 세운다 (의뢰인이 권리자라 저작권 문제 없음) |

**펠팅은 죽지 않는다. 뒤로 간다.** 로드셀 측정(G 보정 · A 바늘 실측)은 며칠짜리라 그대로
하되, 이번 분기의 주작업이 아니다. 지금은 로드셀보다 SLA 프린터가 먼저다.

## ⚠ 이 사업 전체를 사이징하는 미측정 값

    원화 3판 → 출력 가능한 원형까지, 사람 손이 몇 시간인가

한 번도 잰 적이 없다. `hull.py` 는 오메가몬 3판으로 glb 하나 뽑은 게 전부고, 원화 한
세트가 원형까지 통째로 간 적이 없다.

    사람 3시간   하루 여러 건. 사업 된다
    사람 8시간   하루 1건. 본업 병행 빠듯
    사람 3일     중국이랑 차이 없다. 사업 아니다

가격·월 수용 건수·세일즈 문장이 전부 이 값에서 나온다. **지금 「하루」라고 말하는 건
잰 값이 아니라 지어낸 값이다** — `felt-punch` 에서 저장소를 하나 지우게 만든 그 자리와
같다 (`FORCE_PEAK_GF = 300`).
