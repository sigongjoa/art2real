한 줄로

물음: 합친 몸을 다시 그리면 입력 그림과 같아야 한다(가장 센 보존 구조). 망이 낸 몸을 가려짐까지 다시 그린 3면도가 입력과 얼마나 같은가(선 F1)로, 처음 보는 부품 중 틀린 부품을 정답 없이 가려낼 수 있나?

답: 아니다(H27 기각 · AUC 0.55). 종류를 다 맞힌 부품도 자리 · 크기가 조금씩 어긋나 다시 그림 F1 이 0.35 로 낮고, 그 어긋남이 종류 틀림을 덮는다. 몸이 하나뿐인 부품만 가려낸다(0.78).

왜 이 실험을 했나

m2-tr275 에서 「부품 윤곽 안」 은 너무 약해 틀린 몸을 못 가려냈다. 사용자의 보존 구조 제안을 가장 세게 — 합친 몸을 가려짐까지 다시 그리면 입력과 같아야 한다 — 로 다시 봤다.

바꾼 것 하나

새로 재는 자: 바탕 망 출력 → 사양 → 합쳐 짓기 → 입력과 같은 틀로 숨은선 그리기 → 입력 그림과 선 F1(1 화소 안 · 세 장 평균). 정답 숫자로 같은 길을 가면 F1 1.0 이 됨을 먼저 확인했다. 카드는 돌리기 전에 커밋했다(b989d8c3).

왜 이렇게 나왔나

확인한 것

  • 정답 숫자면 다시 그림이 입력과 F1 1.0 이다 — 길에는 문제가 없다.
  • 망 숫자로는 다 맞은 부품도 F1 0.35 다. 1 화소 셈에서 몇 화소 어긋남이 F1 을 크게 깎는다.
  • 몸이 많을수록 AUC 가 떨어진다(1 개 0.78 → 5 개 0.39).

짐작 (아직 확인 안 함)

  • 보존 구조로 종류를 보려면 먼저 숫자를 그림에 맞춰야 한다. 맞춘 뒤 다시 그리면, 남는 차이가 종류 틀림을 드러낼 것이다.

한계

  • 1 화소 셈이 엄하다. 맞은 부품이 178 개뿐이다(몸 많을수록 거의 없음).
  • 못 지은 부품 6 은 F1 0 으로 셌다.

배운 것과 다음

보존 구조(다시 그려 대조)는 숫자가 부정확한 채로는 종류 틀림을 못 본다.

  1. 숫자를 그림에 맞춘 뒤(맞춰 재기 · tr267 길 다) 다시 그려 대조 — 종류 틀림이 드러나는지(Me).
  2. 드러나면, 몸마다 종류 후보를 바꿔 맞추고 다시 그려 가장 같은 것을 고른다(Fi).
