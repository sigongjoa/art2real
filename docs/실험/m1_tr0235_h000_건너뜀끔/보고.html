답: 베끼기는 줄었지만(0.76 → 0.36) 망이 무너졌다. 모든 입력에 같은 그림을 냈다(다양성 0.003 · 정답 0.666). 정해 둔 무너짐 규칙으로 실패다. 시험 3 면도 선 F 는 0.391 로 tr234(0.445)보다 낮다.

왜 이 판을 했나

tr234 혼동 그림에서 망이 입력 그림처럼 비스듬한 상자를 세 칸에 그렸다. 건너뛰는 길이 베끼기 지름길이라고 짐작했다. 사용자가 GPU 둘을 쓰자고 해서 GPU 0 에 대조로 돌렸다.

바꾼 것 하나

tr234 와 모두 같고, 입력에서 64² · 128² 로 건너뛰는 길에 0 을 넣었다.
