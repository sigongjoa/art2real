한 줄로

물음: 여러 장 길(tr233 바탕 0.872)에서 0.95 까지의 차이는 보이는 선과 숨은선 중 어디에 얼마나 있나?

답: 숨은선이다(결정 표 「가」). 보이는 선은 지금 예측 그대로 두고 숨은선만 정답으로 바꾸면 0.950 이다. 거꾸로 보이는 선만 정답으로 바꾸면 0.909 에 그친다. 숨은선 몫은 +0.078, 보이는 선 몫은 +0.037 이다.

왜 이 판을 했나

사용자가 「F 를 0.95 까지 못 올릴까?」 · 「둘 다 비교하자」고 했다. 한 장 길(tr236)은 GPU 에서 돌고 있어서, 여러 장 길은 학습 없이 예측과 정답을 바꿔 끼워 어디를 고쳐야 하는지 먼저 쟀다.

바꾼 것 하나

tr233 바탕 3 면도의 보이는 선 · 숨은선을 정답(정답 3 면도의 그 칸)으로 하나씩 바꿔 끼웠다. 학습은 없다.

결과

시험 99 3 면도 선 F 보이는 선 F 숨은선 F
예측 보 + 예측 숨(지금) 0.872 0.918 0.354
예측 보 + 정답 숨 0.950 0.918 0.808
정답 보 + 예측 숨 0.909 1.000 0.354
예측 보 + 숨 없음 0.823 0.918 0
정답 보 + 숨 없음 0.877 1.000 0
정답 보 + 정답 숨(자 검사) 1.000 1.000 0.855

왜 이렇게 나왔나

확인한 것

  • 숨은선이 지금 0.354 로 가장 약하다. 그것만 정답이면 0.95 에 닿는다. 보이는 선(0.918)은 지금 수준으로도 0.95 를 막지 않는다.
  • 숨은선을 아예 안 그리면 0.823 이다. 지금 숨은선은 +0.05 를 벌고 있지만, 정답 숨은선이 벌 수 있는 몫(+0.13)의 40 % 쯤이다.

짐작 (아직 확인 안 함)

  • 숨은선은 안쪽 구멍 · 홈 · 뒷면 모서리다. 한 시점 그림에는 없고, 여러 시점을 합친 3D 에서 나와야 한다. 지금 합친 3D(9 시점 실루엣 껍질)는 안쪽을 못 본다.

한계

배운 것과 다음

여러 장 길이 0.95 에 닿으려면 숨은선만 정답 수준이 되면 된다. 보이는 선은 지금으로 충분하다.

  1. 결정 표 「가」: 0.95 쪽 다음 판은 숨은선부터 — 합친 3D 를 안쪽까지 맞히는 길(여러 시점 깊이 · 단면) 또는 여러 시점을 함께 보는 숨은선 칸.
  2. 한 장 길(tr236)과 같은 표에 나란히 놓는다.
