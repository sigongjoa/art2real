196 숫자 천장 — 182 의 숫자를 기하로 완벽히 재면 어디까지 오르나 (11-14 · 모델196.py · 손으로 정리 · 학습 없음)

분석

한 줄로

물음: ⑥(182)이 완전한 정답 3면도에서도 「같다」 0.172 에 머무는 게 치수 · 자리 같은 숫자 탓이라면, 숫자만 그림에서 기하로 재면 오르나?

답: 별로 안 오른다. 예측 칸에서 치수 · 자리를 정답으로 바꿔도 0.283 으로 판정선(0.50)에 못 미친다. 판정: 「다시 생각」. 숫자는 몸 종류 · 특징이 맞아야 뜻이 생긴다.

왜 이 판을 했나

tr194 원인 쪼개기에서 정답 칸에 숫자 묶음 하나만 예측으로 바꿔도 「같다」가 크게 깎였다(치수 0.162 · 자리 0.212). 완전한 3면도에서 치수 · 위치는 선의 좌표로 잴 수 있으니, 「정답이 있는 단계는 학습하지 않는다」로 숫자를 기하로 재는 단계를 만들 만한지 먼저 쟀다. 우리 목표는 그림 한 장 → 3면도 → CAD 코드.

바꾼 것 하나

182 예측 칸에서 정답으로 바꿔 끼우는 묶음. 입력(완전한 정답 3면도 · 탐침 시험 99) · 망(182 머리_050) · 자(「같다」 3 % · 모양 맞음 5 %)는 그대로.

결과

시험 99 · 같다 3 % 바꿔 끼운 것 판정선 넘었나
0.172 없음(182 그대로)
0.172 치수
0.283 치수 · 자리 ≥ 0.50 → 기하 재기 만듦 · < 0.30 → 다시 생각 다시 생각

왜 이렇게 나왔나

확인한 것

  • 정답 치수만 넣으면 「같다」는 그대로이고 위상 맞음은 0.707 → 0.616 으로 오히려 떨어진다. 몸 종류를 다르게 고른 칸에 정답 치수가 들어가면 다른 도형의 치수로 쓰인다.
  • 치수 · 자리 · 축이 다 맞아도 0.303 인데, 특징(구멍 · 홈 16 칸)까지 맞으면 0.596 으로 뛴다. 남은 0.40 은 몸 있음 · 종류.

짐작 (아직 확인 안 함)

  • 182 의 칸은 서로 얽혀 있어 묶음 하나만 고치는 길은 다 약하다. 「무슨 도형이 몇 개, 어디에 구멍」을 먼저 알아봐야 숫자가 산다.

⑥ 의 숫자만 기하로 재는 길은 단독으로는 약하고, 정밀은 원래 목표도 아니었다.
