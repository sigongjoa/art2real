분석

한 줄로

물음: 2B 코드 모델 대신 작은 칸 모델(127)을 줄기로 삼으면, 학습 부품을 늘리는 만큼 시험 점수가 오르나?

답: 생성기 시험에서는 오른다. 0.44 → 0.62. 그런데 실제 CAD(Fusion 360) 시험 100 에 처음 대 보니 0.35 였다. 정답 크기 상자 하나(0.44)보다 낮다.

왜 이 판을 했나

11-08 에 작은 칸 모델 127(약 540 만 매개변수)이 2B 코드 모델 168 을 부피 IoU 0.44 대 0.16 으로 이겼다. 사용자가 「경량 모델로 방향을 틀자」고 했다. 우리 목표는 임의의 도면 → CAD 코드이고 계단은 0.35 → 0.50 → 0.80 이다. 경량 줄기의 첫 물음은 「부품을 더 주면 오르나」였다.

바꾼 것 하나

학습 부품 수: 약 1.2 만 → 약 11 만(생성기). 20 바퀴를 돌아 127 보다 예시를 약 3 배 더 봤다. 망 · loss · 시험(생성기 12000~12099)은 127 과 같다.

결과

172 · 20 바퀴 대조 127 목표 넘었나
생성기 시험 100 0.615 0.436 0.50 넘음
실제 CAD 시험 100 0.347 — 0.35 못 넘음

왜 이렇게 나왔나

확인한 것

  • 바퀴가 늘수록 꾸준히 올랐다(5 · 10 · 20 바퀴 = 0.386 · 0.511 · 0.615). 생성기 안에서는 덜 배운 상태였다.
  • 실제 CAD 부품을 지금 칸 문법으로 옮긴 정답 자체의 천장(C)은 0.78 이다(변환된 87 개). 모델이 낼 수 있는 자리는 있었다.

짐작 (아직 확인 안 함)

  • 생성기 부품과 실제 CAD 부품은 모양 분포가 다르다. 그래서 실제 CAD 로 직접 배워야 한다 → tr173.

한계

  • 시드 하나 · 한 번만 돌림. 실제 CAD 시험은 이때 쌍둥이(학습에 같은 그림)를 아직 안 뺐다.
  • 실제 CAD 시험의 자는 11-09 에 고쳤다(물샐틈 없는 메시 · m2_tr0177_h000_원인찾기). 가운데값은 그대로였다.

배운 것과 다음

생성기에서 잘하는 것과 실제 CAD 에서 잘하는 것은 다르다.

  1. 실제 CAD 학습 자료(Fusion 360 reconstruction 7,517)로 학습한다 → tr173.
  2. 정답 크기 상자 하나(0.44)를 첫 칸 대조로 둔다.
