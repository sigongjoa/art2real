한 줄로

물음: 173 이어는 학습 부품에서도 천장보다 한참 낮다. 치수 loss 를 상대 오차로 바꿔 얇은 판 · 벽 두께를 크게 벌주면 학습 부품 점수가 오르나?

답: 아니다. 학습 부품 100 은 0.594 → 0.561 로 오히려 내려갔다(판정선 0.65). 시험 100 은 30 바퀴 0.471 대 0.467 로 비김(24 승 46 패).

왜 이 판을 했나

칸 바꿔 끼우기(정답에 모델 칸 하나만 끼움)에서, 치수만 모델 것으로 바꾸면 학습 부품 100 은 0.81 → 0.66(−0.15), 시험 96 은 0.76 → 0.49(−0.27)로 떨어졌다. 자리는 그다음(시험 0.61), 종류 0.62, 몸 수 0.71. 치수가 가장 크게 깎는다. 치수 절대 오차는 크기와 무관하게 약 0.01 이라, 얇은 치수(< 0.05)는 상대 오차가 35 % 였다.

바꾼 것 하나

치수 항: |o − y| → |o − y| / (|y| + 0.05). 계수는 172 무게 첫 상태에서 옛 항과 같은 크기가 되게 한 번 맞췄다(0.79). 나머지는 173 이어와 같다.

결과

왜 이렇게 나왔나

확인한 것

  • 얇은 치수(상대 오차 0~0.05 구간) 오차는 0.35 → 0.325 로 조금 줄었다. 대신 큰 치수(0.15~0.4 · 0.4 넘음) 오차는 0.075 → 0.099, 0.019 → 0.041 로 늘었다.
  • 정답에 모델 치수만 끼운 점수가 0.663 → 0.572 로 내려갔다. 부피를 크게 깎는 건 큰 치수였다.

짐작 (아직 확인 안 함)

  • 처음엔 얇은 치수를 의심했지만, 부피 IoU 는 큰 치수 틀림에 더 민감하다. 표적을 잘못 골랐다(내 판단 실수).
